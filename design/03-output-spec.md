# 输出规格 v0（草案）：受试者最后拿到什么

> 状态：草案。本文件定义做完之后，受试者拿到什么、每一部分怎么算出来、用什么口吻写。
>
> 配套文件：[核心原则 v3](01-core-principles.md) · [轴表 v0](02-axes-v0.md) · [仓库与发布](04-repo-and-release.md) · [修订记录](changelog.md)

## 0. 总原则

- 报告只写给受试者本人看。
- 没有分数、类型、百分位，也不和任何人比较。
- 每一条描述都能追溯到具体哪一组和原话；拿不出证据的话不写。
- 每一条描述都附上反例、其它可能的解释和把握程度。
- 不给"你应该怎么做"的建议，只给"下次可以留意什么"。

## 1. 报告结构

显示顺序（2026-10-30 修订记录第 7 轮调整，第 11 轮加了"你凭什么选"）：概况、选择图谱、你凭什么选、暂缓的方式、假设、自我预测对照、预测检验、你的看法和下一步、你常用的尺子、披露、数据。没有内容的部分整段不显示，不写"这次没有……""你跳过了这一步"之类的占位话；下面各节的编号沿用最初的顺序。

**和原型的差距**（2026-11-15 核对）。下面写了、原型里还没做的：用时和同意项（1.1、第 2 节）；概况里的"有没有中途终止"（记录里有，报告没显示）；情境差异（1.2，现在只列出被回避的那一类出现过哪些情境）；朋友他评（1.6）；被退回重写的原因（1.9，现在只显示重写了几次，和最后一次审计查出的问题）。

### 1.0 什么时候看报告

**做满 3 轮、一共答满 24 组之前不给看报告的入口**（2026-10-30 修订记录第 9 轮改，原来是第一轮结束时自己选"现在看"还是"做完第二次再看"；第 14 轮加了组数，原来每轮只答一组也算一轮）。理由：知情前后一定要分开统计，而且知情前的数据最要紧；回避要攒三四轮才认得出（见 1.2），早看一次，之后的选择就都算知情后了。

- 正式开始前的说明里先讲清楚："报告要做满 3 轮、一共答满 24 组才能看（每轮十来组），之前做的都会存着。"
- 没攒够时，结束页和首页只写"报告要做满 3 轮、一共答满 24 组才能看。你已经做了几轮、答了几组"，结束页再说一句为什么先不看；首页不出现"看报告"。
- 攒够以后，结束页和首页都给入口，看不看、什么时候看由受试者定；第一次看之前照常先做自我预测（1.6）。
- 轮数只算正式做的、结束了、至少答过一组的；组数算正式做的所有组（整组跳过的也算，没做完的那一轮也算）。已经看过报告的人不受这个限制。两个数是程序里的常数（`REPORT_AFTER_SESSIONS`、`REPORT_AFTER_ROUNDS`），要改只改一处。
- 组数为什么是 24：每一类大约出现"组数 × 3/8"次，出现 4 次才下判断，8 次以上才可能说"明显"；24 组时每一类出现 9 次，判断的各档都用得上。用得上不等于认得出：按网页里的判断方法模拟（每种情形 400 人），明显的回避（本该三次选一次，实际只选 6%）24 组认出约两成，36 组约一半，48 组约七成；随机乱选的人不管多少组，约五分之一会有某一类被标"可能"，约 5% 被标"明显"（门槛就是这么定的，见 1.2）。

**报告不自动重新整理**（修订记录第 14 轮）。整理报告要用受试者的 key 调用模型、花钱，所以只在受试者点了的时候整理：第一次（做完自我预测、点"看报告"），和点"重新整理"的时候。平时打开报告页只显示最近的一份；之后又答了新的组，顶上说一句"还没算进后来答的几组"，给一个重新整理的按钮，并说明要花钱。不设"每次回来都重新整理"的选项。

**试玩报告**：试玩不调用模型，题目直接用例题，报告按规则拼，只示意报告长什么样，开始前就这样说清楚。报告里的类别不写名字，只写"第一类""第二类"……，说明和两头的名字也不显示，免得试玩时就知道了题目怎么分类，影响以后正式做（修订记录第 14 轮）。试玩的组不进正式报告，也不受知情前后的影响。

看过任何一份报告之后，或者在网站里打开了"它是怎么运作的"（点了"打开看"）之后的选择，都标为"知情后"，和"知情前"分开：选择图谱的估计和预测检验只用知情前的数据；知情后的数据另列一张表，看"知道之后，选法有没有变"。这个变化本身也是一条关于自己的信息。

### 1.1 概况

写清楚：组数、用时、整组跳过几次、各种探针用了几次、有没有中途终止，以及是在看过报告之前还是之后做的。如果回答普遍很短，或者受试者说自己读过轴表，也在这里注明，后面的结论相应降低把握。

还要放上受试者结束时说的体验（原话）：哪几组觉得重复、哪里有压力，并和审计记录对照。比如受试者觉得第 5、6 组重复，审计员也把这两组的题标成了相近的主轴，就记一笔"题目可能确实重复了"。对不上的，两边都列出来，不替任何一方下结论；这也是改进出题的依据（12.31 那次，正是这两边对不上，最后只采信了出题方）。

概况里只放一句摘要，一轮一行（比如"第 2 轮：觉得有 2 组像是换了个说法；写了几句感受"），后面带一个链接，点开是那一轮的原话、觉得重复的那几组的三道题，以及审计员给这几道读出的主要取舍。（修订记录第 9 轮：原来把几轮的话都堆在概况里。）

### 1.2 选择图谱（来自选择通道）

每个轴一行（下表为示意，两轮累计）：

表下面用大白话解释"随机期望"：假如每一组都闭着眼睛随便挑一道，这一类大概会被选中几次；实际次数比它多出很多或少很多，才值得留意。

| 轴 | 出现 | 被选 | 随机期望 | 判断 |
|---|---|---|---|---|
| A2 守规矩 / 看结果 | 9 | 0 | 3.0 | 明显回避（把握：高；随机时约 3%） |
| A4 接过来 / 不沾手 | 8 | 5 | 2.7 | 可能偏好（把握：中；随机时约 15%） |
| …… | | | | |

"判断"一栏只有六种写法：明显偏好、可能偏好、看不出倾向、可能回避、明显回避；出现不到 4 次的写"数据不够"。

有知情后的数据时，另列一张同样的表，标明"知情后"，不和上表合并。

另外两项：

- **题位习惯**：比如"12 组里你有 7 组选了第一题"。这既是方法说明（模型已经扣掉了这个影响），也是一条关于自己的小信息。
- **情境差异**：如果回避只出现在某一种情境里（比如只在工作题里绕开 A5），单独指出来。

**怎么算**：用一个选择模型估计每个轴"被选的倾向"，同时扣掉题位的影响。

```
P(选第 i 题) = exp(β[轴i] + γ[题位i]) / ( exp(β0) + Σj exp(β[轴j] + γ[题位j]) )
```

- β[轴]：这个人对该轴的倾向（取相对值，各轴之和为 0）；γ[题位]：题位习惯；β0：整组都不选的倾向。
- 用贝叶斯方法估计，先验取均值为 0 的正态分布。参数只有十来个，在浏览器里就能算。
- 门槛（已用模拟数据校准过一次，2026-10-30）：
  - 对每个轴算两个后验概率："它的倾向比全部轴的平均低出一截"和"高出一截"。"一截"取 0.5，相当于被选的几率只有平均的六成左右（或高出六成多）。
  - 只看后验概率会大量误报：8 个轴、两个方向一起看，完全随机选的人也常有某一项看起来很极端（初稿的 0.9 / 0.75 门槛下，随机选的人约四到五成会被判出至少一条"可能"）。所以再和"完全随机选"比：保留这个人的题位习惯和跳过倾向，把各轴倾向都设为 0，按同样的题目模拟 300 个随机作答者，看他们 8 个轴、两个方向里最极端的那个值，有多少比例不低于这个人的值。这个比例叫"随机时出现的可能性"，报告里直接写出来。
  - **明显**（回避或偏好）：随机时出现的可能性 ≤ 5%，且该轴出现 8 次以上。
  - **可能**：≤ 20%，且出现 4 次以上。
  - 出现不到 4 次：数据不够。
  - 这样定，"随机选的人被判出至少一条'明显'"的比例约 5%，"至少一条任何判断"约 20%。

**校准结果**（`npm run calibrate`，每种情形模拟 800 人）。"回避 A2"指这个人对 A2 有一个固定的负倾向：−1 时，A2 和两道普通题放在一起，被选的几率约 16%（随机是 33%）；−2 时约 6%。

只选一道（现行做法）：

| 组数 | 随机选的人：误报"明显" / 误报任一判断 | 回避 −1：认出"明显" / 认出任一回避 | 回避 −2：认出"明显" / 认出任一回避 |
|---|---|---|---|
| 12 | 0% / 22% | 0% / 0% | 0% / 0% |
| 22 | 5% / 18% | 0% / 4% | 0% / 7% |
| 33 | 5% / 19% | 1% / 13% | 6% / 47% |
| 44 | 5% / 17% | 8% / 24% | 35% / 70% |

每组再标一道"最不想答的"（best-worst scaling）：

| 组数 | 随机选的人：误报"明显" / 误报任一判断 | 回避 −1：认出"明显" / 认出任一回避 | 回避 −2：认出"明显" / 认出任一回避 |
|---|---|---|---|
| 12 | 0% / 19% | 0% / 12% | 0% / 37% |
| 22 | 4% / 19% | 11% / 28% | 52% / 76% |
| 33 | 7% / 19% | 22% / 41% | 80% / 91% |
| 44 | 6% / 20% | 34% / 57% | 94% / 98% |

另外核对了逐人校正：22 组、爱选第一题的随机作答者（150 人），误报"明显" 2%，误报任一判断 16%，题位习惯没有被误当成轴的倾向。

读法：

- 只选一道时，一轮（12 组）认不出任何回避，选择图谱只会写"数据不够"或"看不出倾向"；两轮（22 组）也很难认出；很强的回避要攒到 33 到 44 组（三四轮）才多半能认出。
- 每组多标一道"最不想答的"，同样组数下认出率大约翻倍：22 组就能认出四分之三的强回避。代价是每组多一个动作，而且"最不想答"本身也是一次表态。
- 这些都是模拟：假设倾向固定、题目质量一样、作答之间独立。真人的数据会更乱，门槛还要拿真实数据再看。
- 决定不加"最不想答的"（修订记录第 5 轮）：不管让人觉得"标了这类题会变少"，还是"它在看我不想答哪个"，都会改变选法。维持只选一道。组数不够、表里全是"数据不够"或"看不出倾向"时，报告直说：要攒到三四轮，这张表才会慢慢有判断。开始前和首页都不说，免得受试者去琢磨系统在看什么。

### 1.2b 你凭什么选（来自回答通道，修订记录第 11 轮加）

选择图谱回答"选了什么"，这一节回答"凭什么选"：同样的选择，背后可能是不同的想法。不加题，从已有的回答里看；只描述说法，不分高低，不测对错（所以不做"直觉还是反思"这类有标准答案的测法）。

**五条推理方式**，每段回答由两遍编码各打一次，没说就是"没体现"，不替受试者补：

| 维度 | 一头 | 另一头 |
|---|---|---|
| 依据 | 看前因后果（这样做会带来什么） | 看经验和迹象（以前怎样、别人怎样） |
| 权衡 | 先保住最坏的情况 | 算整体划不划算 |
| 范围 | 只看这一次 | 当成以后的做法 |
| 可能性 | 说到可能性大小（多半、万一） | 没说 |
| 把握 | 说得很肯定 | 留有余地，或明说拿不准 |

它们大致对应"推理结构"方案里因果、局部/整体、概率、信心校准四条的描述版。

**怎么算**：两遍编码对得上的才算，对不上的那一组这一条不算。一条维度至少 4 次有标签才显示（"可能性"按对得上的回答总数算，因为没说也是一种说法）。报告写成次数，比如"依据：看前因后果 6 次 · 看经验和迹象 2 次（另有 3 次没体现）"。

**同一类取舍里，做法和理由各自稳不稳**：只用知情前、没剔除的组；某一类取舍至少答过 3 次才看。"做法"是编码里的倾向（偏哪一头、看条件、先放一放、走第三条路），"理由"看依据、权衡、范围三条；占到四分之三算"一致"，否则"在变"，标签太少算"看不出"。两样都看不出的那一类不列。下面附一句不带褒贬的读法：做法跟着情境变、理由不变，可能是用同一套想法应对不同的情况；做法不变、理由各不相同，可能是对这类事有个固定的倾向，理由随场合说。

分析模型可以把这些当回答通道的证据写进假设，规则和别的证据一样：至少两条、写反例，不说哪种推理方式更好。

### 1.3 你常用的尺子（来自回答通道）

列出受试者在回答里用过的判断标准，按它出现在几个不同的轴上排序。在 3 个以上不同轴里都出现过的标准，标为"可能的主导尺"，并附上原话。

只列在两组以上反复出现的标准，最多 5 条，其余的只说"另外还有几条没列出来"；这一部分放在报告靠后的位置。只做过一轮时，附一句"至少需要两轮测试才能产出更稳定的结果"。（修订记录第 7 轮：原来列得太多。）

> 示意：**"不吭声会不会被当成答应了"**：出现在 A3、A4、A6 三个轴的 5 次回答里。原话："我得先说清楚，不然下次就默认是我了"（第 3 组）……

**怎么算**：分析模型按固定的编码表给每段回答打标签：

- 倾向哪一极，或者"有条件""暂缓"；
- 用到的判断标准（先记自由文本，再把这个人全部回答里的同义项合并）；
- 在什么条件下会改主意；
- 把判断交给了谁（规定、上级、多数人、专家、时间、运气……）；
- 对应的原文片段。

同一段回答用两个模型（或同一个模型两次独立运行）分别编码。两份标签不一致的地方，标为"低把握"。

### 1.4 暂缓的方式

- 暂缓了几次，分别在哪些轴上；
- 其中**有条件的暂缓**（说清缺什么、补上后会怎样）几次，**开放式的暂缓**几次；
- 补全探针的结果：补上信息后**做了决定**、**又提出一个新缺口**、**仍然暂缓**、**拒绝回答**，各几次。

这一部分只描述，不评价。暂缓本身没有好坏，要看的是暂缓之后发生了什么。

### 1.5 假设（三个通道合起来）

报告的核心是 3 到 5 条假设，每条是一张卡片：

> **假设 2**：碰到要不要"自己变通规矩"的事，你倾向于先找一个能拍板的人，而不是自己定。
>
> - **依据**：两轮里，"守规矩 / 看结果"类的题出现 9 次，你一次都没选（选择通道）；"自己定 / 听别人"类的 3 次回答里，有 2 次提到"先问问领导"（第 2 组、第 7 组）。
> - **反例**：第 9 组爬山那道题，你自己定了路线，没问任何人。
> - **其它可能**：这类题对你来说答案太明显，没什么可说；样本还小。
> - **把握**：中。
> - **可以检验的预测**：下次"守规矩 / 看结果"类的题和别的题一起出现时，你仍然会选别的；如果你选了它，回答里会出现"先请示"或"按规定来"。
> - **你的看法**：像我 / 不像我 / 说不清（可以补一句）

写假设的规矩：

1. 用"在某类情境下，你倾向于……"，不用"你是一个……的人"。
2. 每条至少两个独立证据，最好来自不同的通道。
3. 必须写反例；没有就写"本次没有发现反例"。
4. **替换测试**：这句话放在大多数人身上是不是也成立？成立就删掉（防巴纳姆效应）。
5. **可证伪测试**：说不出什么样的选择能推翻它，就删掉。
6. 不用评价性的词：成熟、理性、幼稚、更好、更差、太……
7. 回答一个问题："这条假设替受试者完成了哪一步判断？"如果答案是"替受试者下了结论"，就改写成一个问题。
8. 不写只在某一道题里出现的具体细节（具体的人、科目、地点），用类别说。比如"倾向于先问体育老师"要写成"倾向于先找能拍板的人"。（修订记录第 7 轮补。）

程序先查两样：证据不够两条的直接删（审计员只能改写说法，补不了证据）；陈述和预测里有没有词表里的评价性、标签性的词。然后审计员逐条检查以上 8 点，词表查出的问题也一并交给它：能改好的由审计员改写陈述和预测，改不好的删掉；改写以后还带着词表里的词的，同样不进报告。改写和删除的条数写进披露部分。（2026-11-15 改：原来词表查出问题、审计员又放行时，这条假设会被直接删掉，连"可能更好"这种普通说法也会中招。）

### 1.6 自我预测对照

受试者第一次看报告之前，用大白话列出 8 个轴，请受试者排一排："我觉得自己最常选哪类、最少选哪类"。然后和实际选择放在一起看。"实际"只列选择图谱里已经下了判断（可能或明显）的轴。没猜过，或者全都还是"数据不够""看不出倾向"时，这一部分不出现，猜测先存着，数据够了再放在一起。样本小的时候按估计值排名次只是噪声，不拿来对照。

如果有朋友参与他评，也放进来，三列并排："你以为的""朋友以为的""实际的"。

这一步会让受试者知道轴的存在，所以和第一次看报告放在同一个时刻：从这以后的选择都算知情后（见 1.0）。

### 1.7 预测检验

用留一法检验选择模型：每次拿掉一组，用其余各组估计参数，预测被拿掉的那一组会选哪题。只用知情前的数据。报告三个数：

- 预测命中率；
- 随机基线（33%）；
- 题位基线（只按题位习惯猜的命中率）。

如果命中率没有明显高于题位基线，报告要直说："关于选择的描述，目前没有比'你爱选第几题'多出多少信息，请把它们当作很弱的线索。"组数不够、做不了检验时，这一部分不出现。

### 1.8 你的看法和下一步

受试者对每条假设的反馈，和预测检验放在一起，会落进四种情况：

| | 预测准 | 预测不准 |
|---|---|---|
| **像我** | 比较稳的自我认识 | 可能是心目中的自己，不是行为里的规律；也可能是一句放谁身上都对的话 |
| **不像我** | 值得多看一眼：也许是巧合，也许是题目的问题，也许是平时不太注意的地方 | 撤回 |

"不像我 + 预测准"这种情况，系统不裁决，也不为此加题：明知在被检验，之后的选择会带上"证明给你看"的成分，很难再当证据用。报告把这个不一致摆出来，并提供**回看**：把这条假设依据的那几组原样调出来（当时的三道题、选了哪道、怎么答的），受试者可以逐组写一句"当时为什么这样选"。这对应治疗性评估（Finn）里的"扩展询问"。其它情况下，受试者也可以随时回看任何一条假设的依据。

**回看批注怎么用**：

- **进入整合，但只当自述。** 批注会交给分析模型，在三个通道合起来出假设（1.5）时参考，标为"知情后自述"，因为是看过报告之后写的。
- **只能增加解释，不能推翻证据。** 批注可以写进假设卡片的"其它可能"，标明"你的说法"；但不能删除假设、不能降低把握，也不改选择图谱（1.2）和预测检验（1.7）。人对自己为什么这样选的解释常常不准（Nisbett & Wilson 的研究、选择盲视实验），所以假设的去留只看行为证据和预测结果。
- **例外：指出题目问题的批注。** 如果批注说的是题目本身的问题（看不懂、有歧义、情境不合理），转给审计员复查那道题；审计员确认有问题，这一组从证据里剔除。这改的是数据质量，不是采信自述。
- **审计员把关。** 假设被删除或改写，必须指向行为证据、预测结果或被剔除的组；只凭批注做的改动，退回。
- **不出这台设备。** 和其它记录一样，批注只存在受试者的浏览器里，只发给受试者自己配置的模型；平台上没有跨用户的整合模型，批注也不会被拿去改进系统。

最后给 1 到 3 条"下次可以留意的时刻"，比如："下次有人默认某件事归你的时候，可以留意自己第一反应是先开口，还是先等等。"不给建议。这一块默认收起，标题上写明"看了可能会影响下次的选择，想看再点开"。（修订记录第 9 轮。）

### 1.9 披露

从记录自动生成，不靠出题者自述：

- 这次看了哪三样：选择（选了哪道、没选哪两道、整组跳过）、回答（标准、暂缓、补上信息之后怎么做）、自我预测和结束时的体验；题目背后是八类取舍，每组三道来自不同的三类，题位随机。开场说明里不提这些，这里补全（核心原则第 1 节第 6 条）；
- 出题时参考了受试者开始时选的身份，注明它只用来出题，没有用来分析；
- 每一组的三道题各属于哪一类取舍（写名字，不写 A1 到 A8 的代号）、什么情境、在第几题位；
- 哪些题被审计员退回重写过，为什么；
- 哪些是探针，哪些地方刻意留了信息缺口；
- 出题、审题用的是哪些模型（按每轮开始时记的，几轮之间换过就都列出来），写这份报告、核对假设用的是哪个（按这次整理时实际调用的，修订记录第 14 轮；原来写的是最后一轮开始时记的，中途换过模型就会写错）；审计和出题如果是同一家厂商，注明"这次审计的独立性较弱"；
- 这份报告做不到什么：样本小时的不确定性；读过项目的说明可能带来的影响；它不能用来评价任何人。

### 1.10 数据

- 所有记录只存在这台设备的浏览器里；
- 可以导出成一个 JSON 文件，也可以一键删除；
- 也可以只删某一轮：用到这一轮回答的报告、对这些报告的看法和这一轮的批注一起删掉（报告里引了原话）；"看过报告"这件事不会因此撤销，之后做的照样算知情后；
- 换了设备或浏览器，可以导入之前导出的记录，接着做。导入是整个替换，不是合并：这台设备上已经有记录时，先问一句再换。

## 2. 记录的最小字段

报告里的每一句话，都必须能从这些字段算出来：

```
session      id、开始时间、软件版本、轴表版本、各角色使用的模型、
             开始时选的身份（只用来出题，不进分析的证据）、
             同意项（是否记录用时、是否邀请他评）、
             第一次看报告的时间、第一次在网站里打开说明的时间（取早的那个，区分知情前 / 知情后）
rounds[]     序号
             offered[3]：题目 id、主轴、次轴、包装（情境 / 角色 / 分量 / 抽象程度）、
                         题位、题面、出题模型、审计结果（通过 / 退回次数 / 问题）
             choice：题目 id，或"都不选"
             answer：原文
             probes[]：类型（轻追问 / 补全）、提示语、回答、是否拒绝
             用时（仅在同意时记录）
coding[]     每段回答的两份编码（含五条推理方式）、二者是否一致、编码规则的版本
             （旧版本编的、格式不对又修不了的，整理报告时重编一次）
experience   结束时的体验反馈：觉得重复的组、感到压力的地方（原话）
self_prediction、other_prediction（可选）
hypotheses[] 文本、证据引用、反例、其它解释、把握、预测、受试者反馈、
             回看批注（逐组；指出题目问题的，附审计员复查结果）
```

## 3. 报告不做什么

- 不出分数、类型、百分位，不和任何人比较；
- 不诊断，不贴标签；
- 不给"你应该……"的建议；
- 不把单次观察写成规律，单次的写明"单次观察"；
- 不替受试者解释"不像我"。
